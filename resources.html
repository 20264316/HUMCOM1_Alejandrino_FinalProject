Free resources for first-years

Everything here is free. These are the sites I used most this semester.

Learning HTML and CSS

  • W3Schools HTML Tutorial: short lessons with a "Try it Yourself" editor.
  • W3Schools CSS Tutorial: selectors, colors, borders and more.
  • MDN Learn Web Development: the full reference, written by browser makers.

Tools

  • Visual Studio Code: the free code editor we used in the lab.
  • GitHub Pages: put your site online for free.
  • WebAIM Contrast Checker: check that your text is easy to read.

Why this site exists

This site supports UN Sustainable Development Goal 4: Quality Education by sharing what I learned with other Filipino first-years.
